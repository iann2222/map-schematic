# Data Sources and Attribution

This project uses the following data sources:

- Natural Earth. Public domain data provided by Natural Earth. https://www.naturalearthdata.com/
- Natural Earth Shaded Relief. Public domain raster relief data provided by Natural Earth. https://www.naturalearthdata.com/downloads/10m-raster-data/10m-shaded-relief/
- GeoNames. Licensed under CC BY 4.0. https://www.geonames.org/

The official data pack may include `hillshade_3857.png`, a projected derivative of the Natural Earth shaded relief source.

When redistributing data packs or exported materials built from these sources, keep this attribution intact.
