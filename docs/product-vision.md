# Map Schematic 產品願景

本文件只描述產品目標、體驗方向與完成狀態。現行程式架構見 `architecture.md`，專案格式與資料包規格分別見 `project-format.md`、`datapack.md`。

## 產品定位

Map Schematic 是一套離線地圖示意圖製作工具，協助使用者以真實地理輪廓為基礎，快速製作適合報告、簡報、研究、出版與溝通用途的地圖。

產品重點不是提供導航、GIS 分析或街道級地圖，而是降低製作「資訊清楚、比例合理、仍可編輯」之中尺度示意圖的門檻。

## 核心原則

- **離線優先**：一般使用過程不依賴外部 API、地圖瓦片或即時服務。
- **官方資料包**：底圖、地名與地形資料只由可驗證的官方資料包提供。
- **真實地理基礎**：示意圖可以簡化，但不以手繪猜測取代真實地理位置與輪廓。
- **可回編**：專案檔保存物件、樣式、排序、畫布與歷史，不只保存最終圖片。
- **清楚勝過複雜**：聚焦中尺度製圖，不加入街道、建築、地址與導航功能。
- **可攜與可維護**：專案格式與資料包各自版本化，失敗時不應破壞使用者內容。

## 目標使用情境

- 歷史事件、政經範圍與區域關係示意
- 商業市場、服務範圍與據點分布
- 旅行路線與跨地區行程
- 教學、研究、簡報與出版插圖
- 需要真實底圖但不需要完整 GIS 軟體的視覺溝通

## 地圖尺度

目標支援：

- 全球
- 洲際
- 國家
- 跨行政區域
- 城市層級的概略位置

不以以下用途為目標：

- 街道與建築細節
- 地址解析
- POI 導覽
- 即時交通
- 路線規劃
- 專業 GIS 空間分析

## 目標工作流程

產品維持清楚的四階段流程：

1. **大致定位**：以離線地名或座標找到目標區域。
2. **範圍與比例**：決定畫面範圍、方向與輸出比例。
3. **底圖樣式**：選擇底圖風格及地形陰影。
4. **標示與繪製**：加入地名、點、文字、線、區域與箭頭，調整屬性與排序。

流程應允許使用者返回前一步修改，而不意外丟失已設定的比例、範圍、樣式或標示。

## 目標編輯體驗

- 地名搜尋提供候選結果，由使用者確認，不擅自選定位置。
- 座標搜尋支援常見十進位與 DMS 格式。
- 地名、點、文字、線、區域與箭頭使用一致的選取、拖曳、微調與屬性操作。
- 物件排序、刪除與清除具有清楚回饋。
- Undo／Redo 以操作差異為基礎，並可隨專案保存。
- 深色與淺色主題使用一致的視覺語言。
- 對話框、錯誤提示與危險操作由應用程式自行呈現，不依賴不一致的系統 UI。

## 專案與輸出目標

- `.mapproj` 可重新載入並繼續編輯。
- 舊版專案可透過明確 migration 升級。
- 儲存失敗不破壞原檔，並保留上一份有效備份。
- PNG 適合一般高解析圖片用途。
- SVG 保留真正向量底圖與標示；地形陰影可作為內嵌點陣層。
- PDF 具有與畫布比例一致的頁面輸出。
- 匯出可選擇無外框或簡潔畫框。
- 系統字型名稱隨專案保存；其他裝置缺少字型時使用 fallback。

## 未來方向

- 在真正需要時升級 `.mapproj` schema，將結構資料與視覺 style 分離
- 評估多圖層能力，而不是在尚未支援時宣告不完整契約
- 提供可維護的樣式模板與自訂底圖配置
- 視資料量與效能需求評估更有效率的向量資料格式
- 在發布流程成熟後加入 CI／GitHub Actions

任何擴充都必須維持離線運作、官方資料包與中尺度產品邊界。
